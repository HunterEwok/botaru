# Decisions

These are the decisions the skeleton rests on. A decision number never changes. Documents and the rule registry refer to a decision like this: (D-33).

Every decision is recorded in its current form. If a later decision refines an earlier one, this is visible in the "Links" column, and the text of the earlier decision no longer contains what was canceled.
