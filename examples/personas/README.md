# Lens personas

Example persona addenda of the skeleton commission lenses (COM-19, D-117). The tenant charter pins each file by hash in `commission.lenses.<lens>.persona`, and the core appends it after the reviewer persona for every review of that lens. A tenant writes the addendum of its own lens `x_<name>` the same way. Like every persona, an addendum permits nothing and says nothing about seats, the queue or leaving (GOV-29).
